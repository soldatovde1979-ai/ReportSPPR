# SPEC.md: Аналитика и аудит обращений 1С (VBA + Gemini API)

## 1. Цель проекта
Автономный аудит обращений службы технической поддержки 1С (СППР): пакетная классификация и оценка качества решений через Gemini API, расчет бизнес-метрик (SLA), ведение системных логов и генерация интерактивного HTML-презентационного отчета без сторонних облачных сред.

## 2. Стек и окружение
* **Среда исполнения:** Microsoft Excel (VBA 7.x, 32/64-bit).
* **Среда разработки:** VS Code + синхронизатор vba_sync.ps1.
* **Сетевые вызовы:** MSXML2.ServerXMLHTTP.6.0.
* **Кодировки и потоки:** ADODB.Stream (UTF-8).
* **Модели ИИ:**
  * Пакетная разметка (Batching): gemini-2.5-flash
  * Выводы архитектора (Root Cause): gemini-2.5-pro

## 3. Функциональные требования
1. **Загрузка и валидация данных:** Чтение листа Data, фильтрация по заполненной дате cls.
2. **Расчет SLA:** Подсчет рабочих часов (WORK_HOURS = 8) без учета выходных.
3. **Батчинг:** Пачки по 40 тикетов, вызов Gemini API с response_schema.
4. **Root Cause:** Генерация выводов архитектора через модель Pro.
5. **Логирование:** Листы Logs и Token в книге Excel.
6. **Экспорт отчета:** Рендеринг HTML в UTF-8 на базе template.html.
